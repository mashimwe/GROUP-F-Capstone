Title: How to change your Wi-Fi network name and password
Category: general_faq
Source: Team-authored, synthetic

To change the Wi-Fi name (SSID) or password, log into the router's admin page (usually by typing its IP address into a browser), find the Wireless or Wi-Fi settings section, update the name and password fields, and save/apply the changes. All devices will need to reconnect using the new password afterward. This is a self-service action and does not require a support ticket.
