Title: When and how to factory reset a router
Category: router_modem_issue
Source: Team-authored, synthetic

A factory reset should only be used after a power cycle has failed to resolve the issue, since it erases all custom Wi-Fi names, passwords, and settings. To reset, hold the small recessed reset button on the back of the router for 10 seconds until the lights flash, then set up the Wi-Fi name and password again from the router's default admin page. This is appropriate for persistent configuration corruption, not for a simple loss-of-signal problem.
