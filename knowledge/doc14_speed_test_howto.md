Title: How to run a reliable home speed test
Category: general_faq
Source: Team-authored, synthetic

For an accurate speed test, connect a single device directly to the router by cable if possible, close other applications, and pause any downloads or streams on other devices. Run the test at least twice, a few minutes apart, since a single result can be affected by temporary network conditions. Compare the result to the plan's advertised speed rather than to an unrelated benchmark.
